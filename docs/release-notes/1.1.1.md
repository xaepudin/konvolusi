# Konvolusi 1.1.1

**Rediscover the songs you love.**

This update polishes the menu bar experience.

## Highlights

- **New menu bar and in-app mark.** The off-center impulse/ripple from the app
  icon now appears in the menu bar and the status header. Running uses a solid
  center; stopped uses a hollow center and dimmed rings. The menu bar mark is 16 pt
  so it sits comfortably among system items.
- **Panel fits its content.** The menu bar panel now shrink-wraps instead of
  leaving large top and bottom gaps.
- **Readable status pill.** The Running/Stopped pill uses primary text on a neutral
  capsule with a green or grey status dot, so it stays legible in light and dark
  panels.
- **Licence:** source code is GPL-3.0-only; the generated impulse responses remain
  CC0 1.0.

## Install

1. Download `Konvolusi-1.1.1-macos.zip`.
2. Unzip and drag **Konvolusi.app** into `/Applications`.
3. Control-click the app and choose **Open** the first time. The build is ad-hoc
   signed and not notarized, so Gatekeeper cannot verify it.
4. Allow **System Audio Recording** when macOS asks.
5. Click the Konvolusi ring icon in the menu bar, or open the main window, to
   choose a response.

Requirements: macOS 15 or later, Apple silicon or Intel Mac.

## Notes and limitations

- The app is not sandboxed and is not notarized.
- Only the convolver is implemented; other audio effects are out of scope.
- The 15 included responses are generated by Konvolusi and dedicated to CC0.
- Added latency is typically 16 ms for short responses and 32–38 ms for long ones,
  depending on the output device.
