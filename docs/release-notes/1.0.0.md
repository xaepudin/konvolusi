# IRSVerb 1.0.0

IRSVerb is a menu bar app that applies an `.irs` impulse response to everything
your Mac plays. This is the first public release.

## Highlights

- **Universal app** for Apple silicon and Intel Macs.
- **System-wide convolution** through a Core Audio process tap. No virtual audio
  driver, no per-app routing, no player.
- **15 built-in responses**, generated on first launch: rooms, halls, a cathedral,
  a plate, a stairwell, a car cabin, a cassette tape, an old radio, a telephone,
  and a physical model of a tin can.
- **Your own `.irs`, WAV, AIFF, CAF, FLAC, or M4A files**, including existing
  existing `.irs` folders.
- **Mix, output gain, bypass, normalization, and live meters** in the menu bar
  panel.
- **Low overhead.** About 0.1% of a CPU core when the panel has never been opened;
  a few percent while convolving a long response.
- **Local only.** No network access, no telemetry, no accounts.

## Install

1. Download `IRSVerb-1.0.0-macos.zip`.
2. Unzip and drag **IRSVerb.app** to `/Applications`.
3. Control-click the app and choose **Open** the first time. The build is ad-hoc
   signed and not notarized, so Gatekeeper cannot verify it.
4. Allow **System Audio Recording** when macOS asks.
5. Click the waveform icon in the menu bar and pick a response.

See the [README](../../README.md) for the full guide.

## Notes and limitations

- macOS 15 or later is required.
- The app is not sandboxed and is not notarized. A Developer ID signed build is
  planned for a future release.
- Only the convolver is implemented; other audio effects are out of scope.
- Third-party impulse response packs are not bundled because their redistribution
  terms are usually unclear. The 15 included responses are generated by IRSVerb
  and dedicated to CC0.
- Added latency is roughly 16 ms for short responses and 32–38 ms for long ones,
  depending on the output device.
