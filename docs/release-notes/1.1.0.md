# Konvolusi 1.1.0

**Rediscover the songs you love.**

Konvolusi is a menu bar app that runs everything your Mac plays through the
impulse response you choose — a room, a hall, a tape machine, a radio speaker, or
a telephone.

## Highlights

- **Rebranded from IRSVerb to Konvolusi.** New name, tagline, app icon, bundle
  identifier (`com.xaepudin.konvolusi`), and release artifacts.
- **New main window** with a fixed Control/Library/Diagnostics/Settings/About
  sidebar. Settings is part of the main window instead of a separate window.
- **Background-friendly lifecycle.** The app appears in the Dock and ⌘-Tab while
  the main window is open. Closing it returns Konvolusi to the menu bar and keeps
  audio running; launching it again reuses the same process. Quit remains in the
  menu bar panel.
- **Simpler IR library.** Add IR… copies one or more files into Konvolusi's
  library; Remove deletes added IRs. The built-in responses are always available,
  and there is no folder picker.
- **Live meters and clearer controls**, with ⓘ explanations for Mix, Output gain,
  Bypass, Normalize, and Levels.
- **Licence change:** source code is now **GPL-3.0-only**. The generated impulse
  responses remain **CC0 1.0**.

## Install

1. Download `Konvolusi-1.1.0-macos.zip`.
2. Unzip and drag **Konvolusi.app** into `/Applications`.
3. Control-click the app and choose **Open** the first time. The build is ad-hoc
   signed and not notarized, so Gatekeeper cannot verify it.
4. Allow **System Audio Recording** when macOS asks.
5. Click the waveform icon in the menu bar, or use the main window, to choose a
   response.

Requirements: macOS 15 or later, Apple silicon or Intel Mac.

## Notes and limitations

- The app is not sandboxed and is not notarized. A Developer ID signed build is
  planned for a future release.
- Only the convolver is implemented; other audio effects are out of scope.
- Third-party impulse response packs are not bundled because their redistribution
  terms are usually unclear. The 15 included responses are generated by Konvolusi
  and dedicated to CC0.
- Added latency is roughly 16 ms for short responses and 32–38 ms for long ones,
  depending on the output device.
