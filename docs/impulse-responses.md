# Impulse responses

## What an `.irs` file is

An `.irs` file is a plain WAV file with an unusual extension. Viper4Android uses
the extension to find convolver kernels; IRSVerb reads the content, so the
extension is only a hint.

Supported input formats: `.irs`, `.wav`, `.wave`, `.aif`, `.aiff`, `.caf`,
`.flac`, `.m4a`. Mono or stereo; other channel counts are truncated to the first
two channels. Sample rates from 8 kHz upward are accepted and resampled to the
running output rate. Bit depths 16/24/32-bit integer and 32-bit float are
supported through AVFoundation. Responses longer than 10 seconds are rejected.

The app lists only files with the extensions above in the selected folder.
"Choose .irs…" adds a single file from anywhere; it is remembered across launches
even if it is outside the folder.

## The built-in library

Fifteen responses are generated deterministically by
`Sources/IRSKit/IRSynthesis.swift` and written to
`~/Library/Application Support/IRSVerb/Impulse Responses/` on first launch.
They are also checked into `Impulse Responses/` so the repository is useful
without running the app.

| Name | Length at 44.1 kHz | Generator | Purpose |
| --- | --- | --- | --- |
| Identity (control) | 1 tap | delta | Prove the engine is transparent; A/B reference |
| Speech Lift | 0.16 s | biquad chain | Rumble cut plus consonant-band lift for dialogue |
| Night Mode | 0.16 s | biquad chain | Equal-loudness bass/treble lift for quiet listening |
| Warm Desk | 0.24 s | short reverb + low shelf | Barely-there space for headphones |
| Studio Room | 0.42 s | short reverb | General-purpose small room |
| Plate | 1.35 s | dense reverb | Bright, no discrete early reflections |
| Small Room | 0.70 s | short reverb | Everyday room |
| Car Cabin | 0.22 s | short reverb + comb | Glass flutter and low-end boom |
| Stairwell | 1.70 s | reverb + flutter echo | Regular echo train off parallel walls |
| Cassette Tape | 0.12 s | biquad chain + saturation | Head bump and dull top |
| Old Radio Speaker | 0.18 s | band-pass + resonance | 1930s box, 60 Hz far below 2.6 kHz |
| Telephone | 0.12 s | band-pass | 300 Hz–3.4 kHz phone line |
| Large Hall | 2.60 s | reverb | The canonical big reverb |
| Cathedral | 4.40 s | reverb | Enormous, slow tail |
| Tin Can | 0.30 s | modal bank | Struck metal shell, inharmonic modes |

The generators are:

- **Reverb:** decorrelated stereo noise with an exponential decay, a one-pole
  low-pass whose cutoff falls as the tail decays, sparse early reflections, and an
  optional flutter train. Seeds are fixed, so output is reproducible.
- **Filter chain:** the impulse response of a cascade of RBJ biquads (low shelf,
  high shelf, peaking, band-pass). This is how "EQ without an EQ" is expressed as
  a convolver kernel.
- **Modal:** a bank of damped inharmonic resonances. This makes a struck object
  rather than a space; `Tin Can` is the demonstration.
- **Delta:** the identity response.

The `LibraryTests` assert measured character rather than trusting the names:
Speech Lift really does lift 3 kHz and cut 60 Hz, Night Mode lifts both extremes,
radio and telephone are band-limited, tape has its head bump, the flutter train
measurably changes the response, and Tin Can's magnitude response is about three
times as ragged as any reverberant response.

Synthesised **spaces** are plausible rather than measured. A synthesised short
room can have a more ragged magnitude response than a real one; if one sounds
honky, lower the mix or use a measured library. The perceptual curves and the
physical model are where synthesis genuinely wins.

## Regenerating the library

```sh
dist/irsconv make-ir --out "Impulse Responses"
# or, at a different rate:
dist/irsconv make-ir --out /tmp/irs --rate 48000
```

`make-ir` writes all fifteen as 16-bit WAV data with an `.irs` extension. The
output is deterministic for a given sample rate. The app calls the same generator
on first launch, at 44.1 kHz.

## Licensing and provenance

The repository ships **only** responses generated by IRSVerb's own code:

- Code: MIT, see [../LICENSE](../LICENSE).
- Generated impulse responses: CC0 1.0 public-domain dedication, see
  [../LICENSE-IRS](../LICENSE-IRS). You can use them in music, videos, games, and
  commercial work without attribution.

Third-party impulse response packs are **not** included. The large Viper4Android
collections that circulate online are usually redistributions of measurements
whose original licence is unknown or absent; a GitHub repository containing them
does not grant a licence, and the README of one popular collection explicitly says
the files do not belong to its author. Many of those files also carry the names of
commercial products (amplifiers, compressors, tape machines), which makes the
provenance question harder, not easier.

The rule for contributions is therefore:

> Commit an impulse response only if you can point to a licence or written
> permission that allows redistribution, and record the source and licence next to
> the file. If you cannot, keep it out of the repository.

The generated library is the safe default. Users can still load any `.irs` file
locally; IRSVerb does not need the file to be in the repository.

If you add a distributable third-party pack, put it in a clearly named directory
with a `LICENSE`/`README` describing the origin and terms, add it to the built-in
list only if the licence permits, and mention it in the main README.

## Third-party and Viper4Android files

Viper4Android stores kernels under:

```
/storage/emulated/0/ViPER4Android/Kernel/                              (Android 9 and earlier)
/storage/emulated/0/Android/data/com.pittvandewitt.viperfx/files/Kernel/  (Android 10+)
```

Copy the folder to the Mac (or copy individual files) and use **Folder…** or
**Choose .irs…**. IRSVerb does not need root, a virtual audio driver, or an
Android device.

Hosted impulse response files are often 44.1 kHz or 48 kHz mono WAV data. IRSVerb
resamples them to the current tap rate, normalizes them by default, and builds the
FFT partitions on a background queue. Loading a 4.4 s response takes a moment but
does not interrupt playback.

## Creating your own

Any audio editor that can export a WAV can produce an impulse response. Common
approaches:

- **Record a real space:** a sine sweep or balloon pop, then deconvolve the sweep
  to obtain the impulse response.
- **Capture a device:** run a signal through a guitar cabinet, tape machine, or
  hardware unit and record the result; use a click or sweep as the input.
- **Design a filter:** export the impulse response of an EQ curve or a short
  synthetic reverb from a plugin.
- **Synthesise:** use `IRSynthesis` as a starting point and add a generator.

Keep the file mono or stereo, trim leading silence, avoid clipping, and keep it
under 10 seconds. IRSVerb normalizes energy by default, so absolute level is less
important than a clean, noise-free tail.

## Why only fifteen?

A convolver is most useful with a small, well-chosen set. Fifteen responses cover
a control, two perceptual compensation curves, everyday spaces, character
effects, large spaces, and one physical model. Five hundred files mostly produce
decision fatigue, and the large online packs have the licensing problem above.

If you want a specific measured space, load it locally. The repository deliberately
stays small and redistributable.
